# Instagram Sidecar - הוראות הפעלה

## שלב 1: הגדרת מסד הנתונים (חד פעמי)
כדי שהמערכת החדשה תעבוד, חובה להריץ את סקריפט ה-SQL ב-Supabase.

1.  היכנסי ל-Supabase Dashboard של הפרויקט שלך.
2.  בתפריט בצד שמאל, לחצי על **SQL Editor**.
3.  פתחי קובץ חדש (New Query).
4.  העתיקי את התוכן של הקובץ `ai_sidecar/retrieval_rpc.sql` מהפרויקט שלך.
5.  הדביקי ב-SQL Editor ב-Supabase ולחצי על **Run**.
    *   הודעת הצלחה: "Success" (או שלא תהיה שגיאה).

## שלב 2: התקנת ספריות
פתחי את הטרמינל ב-VS Code והריצי:
```bash
pip install supabase openai
```

## שלב 3: הרצה
הריצי את הסקריפט היומי כרגיל:
```bash
python run_daily.py
```
תראי לוגים חדשים עם האייקון 🤖 ו-✅/⚠️.

## למה זה טוב? (הערך המוסף)

המערכת שבנינו נותנת לך **3 יתרונות קריטיים** שמערכת רגילה (If/Else) לא יכולה לתת:

1.  **זיכרון ולמידה (The Brain):**
    *   במערכת הישנה, אם היא פספסה קופון של "שני אטיאס", היית צריכה לשנות את הקוד.
    *   במערכת החדשה: ברגע שאת (או המערכת בעתיד) מסמנת "זה כן קופון", המערכת שומרת את הדוגמה הזו.
    *   בפעם הבאה ששני תעלה סטורי דומה, המערכת תשלח ל-AI את הסטורי החדש **יחד עם הסטורי הישן שכבר פתרנו**, וה-AI יבין לבד: "אה, כמו בפעם הקודמת!".

2.  **תפיסת "מקרי קצה" (High Recall):**
    *   משפיעניות כל הזמן משנות ניסוחים ("קוד בביו", "הנחה אצלי", "למזמינות ב-100 שח").
    *   אי אפשר לכתוב חוק לכל ניסוח.
    *   ה-Vector Search מוצא דמיון *רעיוני* ולא רק מילים מדויקות. זה תופס הרבה יותר קופונים.

3.  **יציבות (Safety):**
    *   הוספנו **מגבלת תקציב ($1)** ו-**Guardrails** (חסימת מספרי טלפון/שעות).
    *   זה אומר שהמערכת הרבה יותר בטוחה לשימוש אוטומטי ולא תבזבז כסף או תפרסם שטויות.

בקיצור: בנינו "מוח" שלומד ומשתפר מיום ליום, במקום סתם סקריפט שצריך לתקן כל הזמן.
